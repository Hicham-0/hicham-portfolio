# Hicham El Hanafi — Catalogue Nº 26 · Infrastructure, Considered (V3)

## Quick Start

```bash
unzip hicham-el-hanafi-portfolio-v3.zip
cd hicham-portfolio-v3
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build & Verify

```bash
npm run typecheck
npm run build
npm run start
```
